Git,GitHubのコマンドメモ

Git,GitHubで用いるコマンドを自分用にまとめたものです。
後々追加していく予定です。
間違いがある可能性があります。

初期設定(config)

初めてgitを入れたときにはユーザー情報を設定する

git config --global user.name "ユーザー名"
git config --global user.email "メールアドレス"
--local > --global > --system の順番で優先

Git: コミット関連

ワーキングディレクトリ->ステージングエリア->Gitディレクトリ
の順に進む。

git add {ファイル名} ワーキングディレクトリのファイルをステージングエリアに移す。

{ファイル名}以外にも以下のオプションがある

. 今いるディレクトリ内の変更された全てのファイルを追加
-A | --all 全てのディレクトリの変更されたファイルを追加
