Gitのコマンドメモ

Gitで用いるコマンドを自分用にまとめたものです。
後々追加していく予定です。
間違いがある可能性があります。

初期設定(config)

初めてgitを入れたときにはユーザー情報を設定する

git config --global user.name "ユーザー名"
git config --global user.email "メールアドレス"
--local > --global > --system の順番で優先

Git: コミット関連

ワーキングディレクトリ->ステージングエリア->Gitディレクトリ
の順に進む。

git add {ファイル名} ワーキングディレクトリのファイルをステージングエリアに移す。

{ファイル名}以外にも以下のオプションがある(一部)

. 今いるディレクトリ内の変更された全てのファイルを追加
-A | --all 全てのディレクトリの変更されたファイルを追加

git commit -m "コメント" ステージングエリアからGitディレクトリにコミットする。

-m以外にも以下のオプションがある(一部)

-a | --all 自動的にステージングしてコミット(新規ファイルは除く)
--amend 直前のコミットを変更する(-mなどを使えばコメントの編集)
-p | --patch 一部の部分だけコミット(ステージングはしない)
--allow-empty 変更を追加せずにコミット

Git: 状況確認系

git status 現在のレポジトリの状況を知ることが出来る。

git log リポジトリの変更履歴の確認

オプション(一部)

--oneline 1行で表示
--graph ブランチの分岐をグラフで表示
-n {数字} 数字の分だけ表示
--all 全てのブランチの表示
vscodeに拡張機能「Git Graph」を入れていれば >Git Graph: View Git Graph(Git log) で確認可能。

git branch 今いるブランチと全てのブランチの表示

Git: コミット削除系

コミット前

git restore {ファイル名} コミット前のワーキングツリーの変更を削除(vscodeだと確認が必要?)。

オプション(一部)

-S | --staged ステージしたものをワーキングディレクトリに戻す
-s | --source= 指定したコミットから復元

コミット後

git reset {コミットハッシュ} コミットを削除して巻き戻す。
コミットハッシュはgit logなどで出てくる長い英数字列。

オプション(一部)

--soft コミットだけを削除、ステージングエリア＆ワーキングディレクトリはそのまま
--mixed コミットとステージングエリアを削除、ワーキングディレクトリはそのまま(デフォルト)
--hard コミット＆ステージングエリア＆ワーキングディレクトリ全て削除

git revert {コミットハッシュ} 今のコミットを残して、次のコミットに巻き戻したものを作る。

オプション(一部)

--no-edit エディタを開かずに実行(コミットメッセージを自動で)
-n | --no-commit コミットせずに変更をステージングエリアへ
-m 1 {マージコミットid} マージコミットをrevertするときに使う。1は親はどれかを指定する

Git: ブランチ関連

git branch 現在の全てのブランチを表示する。

オプション(一部)

-a | --all ローカル&リモートのブランチ表示
-vv 最新のコミットidとメッセージを今いるリモートブランチも加えて表示
{新ブランチ名} ブランチの作成
{新ブランチ名} {コミットid} コミットidからブランチ作成
-d | --delete ブランチの削除(マージ済みのみ)
-D 強制的なブランチ削除
-m ブランチ名の変更
--no-merged マージされていないブランチを表示

git checkout {ブランチ名} 特定のブランチに移動する。

オプション(一部)

-b ブランチを作成して移動(git branch不要)
{コミットid} 特定のコミットに移動

git merge {ブランチ名} ブランチをマージ(結合)する。
・マージするブランチがマージ先のブランチに含まれているとき、ブランチの位置のみが変わる。(fast-forward)
・マージするブランチがマージ先のブランチから枝分かれしているとき、新たなマージコミットを作成される。
マージを行ったとき、conflictが起こればマージツールで解消する。

オプション(一部)

--no-ff マージコミットを必ず作成する
--squash マージコミットを作成せず、ブランチのコミットの内容をコピー(マージ履歴に残らない)
--no-commit マージコミットを作成せずにマージ(マージ履歴に残る)
--ff-only fast-forwardのみを許可する
--abort コンフリクト時にマージを中止して、マージ前の状態に戻す
--continue マージのコンフリクトを解消した後、マージを続行する
